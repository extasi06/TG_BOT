# Вопросы математики

Telegram-бот для обучения математике через **педагогическую обратную связь** на основе правил, шаблонов и классификатора ошибок (без внешних LLM API).

## Стек

- Python 3.12+
- pyTelegramBotAPI (Telebot, FSM)
- SQLite
- Модуль: правила + разбор выражений + библиотека шаблонов

## Ключевые модули

| Модуль | Назначение |
|--------|------------|
| `services/error_classifier.py` | Классификация типовых ошибок |
| `services/feedback_templates.py` | Шаблоны ОС (правило, направление, рефлексия) |
| `services/feedback_engine.py` | Сборка сообщения и подбор аналогичной задачи |
| `services/practice_tracker.py` | Метрики до/после обратной связи |
| `utils/expression_parser.py` | Безопасный разбор выражений |
| `data/*.json` | Банк задач (30×4 темы) |

## Запуск

```bash
cd math_bot
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
# Укажите BOT_TOKEN
python create_data.py
python main.py
```

## Переменные окружения

| Переменная | Описание |
|------------|----------|
| `BOT_TOKEN` | Токен @BotFather |
| `DATABASE_PATH` | Путь к SQLite (по умолчанию `./data/bot.db`) |
| `LOG_LEVEL` | Уровень логирования |

## Метрики апробации

В разделе **📊 Статистика** отображаются:

- доля верных ответов **после** показа обратной связи по типу ошибки;
- успех на **аналогичных** задачах;
- снижение повторов одной и той же ошибки.

Подробный отчёт для курсовой — в [REPORT.md](REPORT.md).
